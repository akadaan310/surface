# Quantum Oracle inherited evidence and source custody audit

This additive audit records the inherited requirements at commit `6e97a6c819aba0df79b507da0d71301acc794d07`. It does not grade the scientific adapters being developed after that baseline. The current owner commission authorizes scientific continuation; the older publication-only handoff remains preserved as historical text. Native Surface source, original archives, ledgers and past receipts were not changed by this audit.

The original **COMPOSER Gate 1 evidence remains UNKNOWN**, as do all **eight historical Octave comparisons**, the sparse-array repair and the original wave-stability validation. A bounded search recovered their commissioning text and later descriptions, but no original source-and-result package sufficient to verify those claims. UNKNOWN describes missing evidence in the searched scope; it does not establish that the work never existed. The machine-readable [custody audit](../research/quantum_oracle/evidence/custody-audit.json) records paths, SHA-256 identities, search limits and individual missing-evidence records.

## COMPOSER Gate 1: exact missing material

Original provision 68 requires stable contract/IR, an operational PHANTOM adapter, multi-runtime conformance, event ledger, solvers, AST and Q-Strings, and passing clean-room reproduction. Provisions 19–38 supply its substantive contract; provision 3 requires this COMPOSER milestone before SURFACE. The current owner scope freezes native Surface while scientific work continues; it does not retroactively certify the earlier milestone. [Original constitution](../build/foundation/surface_commission/PHANTOM_COMPOSER_SURFACE_CONSTITUTION_v1.md).

The missing verification package must contain:

1. Original COMPOSER source/revision/tree, immutable archive manifest and declared source identity.
2. Versioned Substrate, Operation and Machine contracts; canonical JSON and compact binary IR; compatibility/error rules and semantic registry.
3. Operational PHANTOM adapter and executable vectors for exact/loss-accounted encodings, operator traces and unchanged-reference agreement.
4. Python, TypeScript and C++ SDK evidence, with Julia/Octave reference bridges, versions, invocation logs and measured tolerances.
5. Causal ledger events and externally bound roots spanning ingestion, state derivation, solver/numerical observations, rendering issue/completion, verification and presentation where claimed.
6. Symbolic and implementation ASTs, solver/rewrite side conditions, finite budgets, counterexamples, guarded/compound Q-Strings and cycle refusal.
7. Independent clean-room replay with locks, licenses, input/output hashes, denominators, environment and result receipts.

The later Surface commission compiler, native bridge and original PHANTOM replay each supply useful bounded evidence; none is this missing complete package. The constitution explicitly excludes `PHANTOM_COMPOSER_SEED_v0.5.zip` as an authoritative replacement. If the original cannot be acquired, a new implementation must carry a new identity and evidence history.

## Resume and verification

For a recovered original, first retain its bytes and acquisition provenance, compare against any independently known digest, inspect its manifest and declared environment, and then issue a bounded replay into a new destination. For an absent original, retain UNKNOWN and implement independently authorized new work under a new identity. The audit JSON supplies the exact required artifact list for each gap.

The additive verifier checks the JSON inventories' source hashes, byte spans, required counts and preserved UNKNOWN records. It deliberately does not infer scientific acceptance or rerun historical experiments:

```sh
python3 -B research/quantum_oracle/evidence/verify_custody_audit.py
```

The source references below `build/foundation/` require the existing exact materialization; materialize the pinned foundation first when using a fresh checkout. No CI trigger or workflow was changed.
