## Run the research tools

Python 3.11+ and a C++20 compiler are the core host requirements. NumPy is needed only for the original V3 scientific fixture. Node 24+ enables the optional preserved University TypeScript demo.

```sh
git clone https://github.com/akadaan310/surface.git
cd surface
python3 tools/verify_repository.py
python3 tools/materialize_foundation.py
python3 tools/polyia_surface_demo.py --output build/polyia-demo.json
python3 tools/build_native.py --test
```

`materialize_foundation.py` reconstructs the exact large handoff ZIP from two pinned Git chunks, then exposes six immutable reference packages under `build/foundation/`. It verifies 621 file records and does not execute extracted code. Use `--check` to recheck an existing materialization. [Source custody and tests](docs/FOUNDATION_INVENTORY.md).

The build script writes fresh receipts to its historical default paths. Preserve those files first when collecting a new named run; the consolidation's fresh receipts live separately under `evidence/consolidation/`. Native test success is distinct from Android execution.
