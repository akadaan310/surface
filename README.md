# SURFACE

Canonical repository for the native Surface renderer, PHANTOM / COMPOSER research lineage, Quantum Oracle V3, physical models, state machines and recovery harnesses.

The owner designated this repository on 2026-10-25. A verified native source checkpoint is being migrated here with its exact scientific evidence and immutable upstream archives. The migration preserves local checkpoint `f002eece5a5915b886d77dce1807890588282afd` and the original recovery lineage.

Surface is a native C++ renderer with an Android lifecycle shim. It does not use a browser, WebView, WebGL or a third-party rendering engine.

Current Android artifact: Surface Recovery 0.1.1 (ARM64, Android 10+). A host JNI regression and static APK checks pass; launch on a physical Android device remains unverified. Scientific expansion remains governed by explicit acceptance gates.

Repository population and the consolidated continuation package are in progress. Signing credentials are private and excluded.
