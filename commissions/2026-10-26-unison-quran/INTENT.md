## Native and physical boundaries
- Arabic proper shaping requires a shaping-capable platform text layer; the existing native CPU raster does not expose this. A standalone offline inspection HTML uses platform text shaping as a preview, not as a shipped native Android renderer.
- Astronomy is an opt-in layer with source, epoch, frame and uncertainty, never a visual proof of Qur'anic meaning. Current 10k Gaia slice is NOT a 1.6-billion-object live universe simulation.
- Control bits, native letter weights, grapheme identifiers, phoneme durations, quantum basis amplitudes and physical stars retain different data types, axes and clocks.
- A 7-axis HyperRuler is a declared coordinate chart, not evidence for seven physical space dimensions.
- OS app launchers/simulator pathways only use documented permissions/authorizations; no root or jailbreaking bypass.
